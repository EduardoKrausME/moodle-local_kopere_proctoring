# Kopere Proctoring — Documentation website

Standalone, bilingual static website modeled on the documentation branch of Moodle MCP.

- Browser-language entry point: `index.html`.
- PT-BR: `pt_br/index.html` and `pt_br/guia/`.
- English: `en/index.html` and `en/guia/`.
- Shared presentation: `styles.css`, `script.js`, `theme-init.js` and `favicon.svg`.

To publish, select GitHub Pages source **docs** branch and **/(root)**. Plugin source remains on **master**. This site was reviewed against the source tree on 2026-10-26. Browser observations are not proof of cheating or AI usage.
