Integração Moodle MCP

Cinco ferramentas READ/WRITE com permissões e confirmação.

Descoberta de ferramentas

Com local_mcp instalado, o servidor descobre classes/mcp/provider.php. Não existe endpoint MCP próprio no Proctoring. O MCP é opcional e aplica escopos de autenticação e permissões Moodle.

Ferramentas READ

kopere_proctoring_list_policies exige moodle/site:config. kopere_proctoring_get_quiz, kopere_proctoring_list_attempts e kopere_proctoring_get_attempt_logs exigem mod/quiz:viewreports no contexto da atividade.

Ferramenta WRITE

kopere_proctoring_set_quiz_enabled exige mod/quiz:manage, suporta prévia e precisa de confirmação explícita. Consulte state_hash por get_quiz e envie como expected_hash para evitar alterações baseadas em estado desatualizado.

Parâmetros e privacidade

Use o ID do módulo do curso cmid, não quiz.id; attemptid equivale a quiz_attempts.id. Limites de listagem são de até 100 registros. IP, user agent e resolução só retornam nos logs quando include_technical:true. Ativar ajusta questionsperpage para 50; desativar não restaura o valor anterior nem apaga os registros. Consulte docs/MCP.md.
