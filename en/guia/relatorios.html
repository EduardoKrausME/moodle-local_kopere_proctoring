Attempt records and event review

Stored records, review process and evidentiary limits.

Records

The local_kopere_proctoring_att and local_kopere_proctoring_log tables store attempt and event information, including IDs, timestamps, actions and technical metadata when collected.

Reviewing incidents

Identify the quiz, student, attempt, timestamps, active policies and reported failures, then review the complete event sequence. Record human assessment and provide an appropriate appeal process.

Interfaces

The user-data.php page exposes user data and optional MCP tools list attempts and logs. lib.php references report.php, but that file is absent from the inspected master source tree; verify your installation before relying on that report.
