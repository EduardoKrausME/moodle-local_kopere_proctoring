Installation and requirements

Dependencies, installation and validation of the plugin.

Dependencies

The component is local_kopere_proctoring, installed in local/kopere_proctoring. Its version.php requires local_kopere_dashboard at internal version 2026101900 or later and declares Moodle requirement 2021041900. Test against the actual Moodle, PHP and theme versions you deploy.

Procedure

Install or update Kopere Dashboard, place Proctoring in local/kopere_proctoring with its policy/ folder intact, run the Moodle plugin upgrade and inspect the policy administration page. Rehearse with test accounts and a sample Quiz before any live assessment.

Additional integration

local_mcp is optional and is not a replacement for Dashboard. Install it only to expose MCP tools with READ/WRITE scopes and Moodle permission checks.
