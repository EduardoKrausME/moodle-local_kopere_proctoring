Privacy and troubleshooting

Personal data, runtime issues and unbundled capabilities.

Data and rights

The classes/privacy/provider.php provider implements context-specific Moodle metadata, export and deletion, including snapshot files when applicable. Institutions must define purpose, lawful basis, transparency, retention, restricted access and procedures under applicable laws.

Troubleshooting

If the preparation screen is missing, check per-quiz enablement, attempt ownership, Moodle hooks and JavaScript loading. For missing events, inspect browser console and web-service calls and reproduce the issue using a test account.

Features not bundled in this source tree

The README discusses authorship analysis and teacher approval, but the inspected master tree does not contain policy/authorship or policy/approval. Check separately installed extensions before describing those as bundled policies. Isolated signals do not prove cheating or AI usage.
