Quiz configuration

Per-quiz enablement, global policies and important limits.

Global policies

Kopere Proctoring administration enables, disables and orders proctoringpolicy_* subplugins. Policies can add settings for text, email recipients and violation thresholds. Their global order also organizes the preparation requirements.

Quiz-level settings

Edit a Quiz, enable Enable Proctoring and configure only the necessary controls. Test a complete attempt using the permissions students will have, including accessibility tools.

Pagination

Important: enabling Proctoring sets Quiz questionsperpage = 50, in both the form and MCP tool. This does not guarantee a single page for quizzes with more than 50 questions. Disabling via MCP does not restore the previous pagination.
